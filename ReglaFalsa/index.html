Información del método

La regla falsa es un método numérico que permite aproximar raíces de ecuaciones. Utiliza dos extremos de un intervalo donde la función tiene signos opuestos.

En cada iteración se calcula una nueva aproximación y se actualiza el intervalo hasta alcanzar el error permitido.
