¿Cómo funciona el patrón MVC?

MVC significa Modelo, Vista y Controlador. Es una forma de organizar un programa separando los datos, la interfaz y las acciones.

📦 MODELO

El Modelo contiene y organiza los datos que utiliza la página.

En este proyecto el Modelo almacena la información de los personajes de Gears of War.

modelo.personajes

🖥️ VISTA

La Vista es todo lo que el usuario puede observar en la página.

Está formada principalmente por HTML y CSS.

Aquí se encuentran los títulos, botones, tarjetas, colores y textos.

index.html + style.css

⚙️ CONTROLADOR

El Controlador recibe las acciones realizadas por el usuario.

Después consulta el Modelo y actualiza la Vista.

En este proyecto está programado principalmente con JavaScript.

controlador.iniciar()

¿Qué hace cada elemento?

HTML

HTML crea la estructura de la página. Define títulos, párrafos, botones, tarjetas y el selector de personajes.

CSS

CSS se encarga del diseño visual. Cambia colores, tamaños, espacios, bordes y efectos.

JavaScript

JavaScript permite que la página responda a las acciones del usuario. En este proyecto también contiene el Modelo y el Controlador del patrón MVC.
